# SafeStep: 재난 대피 안내 웹 앱 (기획서)

이 문서는 SafeStep의 요구사항, 아키텍처, AI 시뮬레이션 로직, UI 디자인 명세를 담고 있습니다.

---

# 1. 프로젝트 목표
SafeStep은 긴박한 재난 상황을 위해 설계된 모바일 우선, 클릭 기반의 재난 대피 챗봇 안내 앱입니다. 사용자의 인구통계학적 프로필을 바탕으로 위험 구역(홍수, 건물 붕괴, 산불, 빙판길)을 동적으로 우회하여, 가장 적합하고 혼잡도가 낮은 대피소를 찾아 안내합니다.
본 앱은 실시간 재난 데이터 연동(기상청 API, 행정안전부 재난문자 API, 대피소 혼잡도 실시간 수집 등)을 구현하기 위한 인프라 및 데이터 접근성의 한계로 인해, 현재는 사전 정의된 시나리오 기반의 시뮬레이션 프로토타입으로 구현하였습니다. 향후 실시간 API 연동이 가능해질 경우, 실제 재난 상황을 반영한 동적 대응 시스템으로 확장될 수 있도록 설계되었습니다.

---

# 2. 기술 스택
구조: HTML5 기반 단일 페이지 애플리케이션(SPA).
스타일링: 커스텀 속성(변수), 고대비 요소, CSS 애니메이션을 활용한 순수 CSS3.
로직: 챗봇 흐름 제어, 동적 SVG 렌더링, 안전 적합성 계산을 위한 순수 ES6 JavaScript.
지도 및 경로: 외부 지도 API 로딩 없이 인라인 동적 SVG 생성 방식 채택 — 본래 목표는 사용자의 상황에 맞는 완전한 맞춤형 앱 개발이었으나, 위치 데이터 및 지리적 컨텍스트의 범용화 한계로 인해 우선 한국외국어대학교 서울캠퍼스를 중심으로 한 지역 특화 모델로 구현함.

# 3. 동적 AI 시뮬레이션 로직

# A. 다중 기준 점수 산출 공식 
군중 분산 균형 조정 및 사용자 인구통계에 맞는 대피소 능력 매칭을 위해, 순위 알고리즘은 다음을 평가합니다:

$최종 점수 = 기본값 (100)− 거리 패널티 − 혼잡도 패널티 + 시설 가산점

1.근접성: 출발 위치로부터의 유클리드 거리에 따라 대피소에 패널티 부여.
2. 혼잡도 패널티 (부하 분산):
- 점유율 ≥98: 과밀 방지를 위해 제외 또는 강한 패널티 (−100점).
- 점유율 ≥85: 패널티 부여 (−35점).
- 점유율 <45: 여유 공간 활용을 위해 가산점 부여 (+15점).

3. 시설 가산점:
- 장애인: 휠체어 경사로 지원(wheelchair 태그) 필요. 지원 시 +50점, 미지원 시 −60점.
- 임산부: 의료 시설 및 영유아 돌봄 시설 필요. 각각 +30점, +20점.
- 고령자 / 어린이: 해당 시설 보유 대피소에 가산점 부여.

# B. 재난 유형별 커스텀 필터
- 홍수: 침수 위험 방지를 위해 지하 구조물(아파트 지하 등)에 −100점 패널티.
- 지진: 내진 보강된 체육관 및 개방 공간 우선순위 부여.
- 산불: 산림 경계 인근 대피소에 패널티 부여.
