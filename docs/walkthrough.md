# SafeStep: 대피 안내 및 사용 설명서

이 문서는 SafeStep의 사용자 인터페이스 흐름, 안전 기능, 동적 지도 동작 방식을 설명합니다.

---

## 📱 대피 사용자 흐름

### 🚨 1. 재난 알림 대시보드 (Step 0)
- 재난 유형 선택기: 호우・침수, 지진 발생, 산불 확산, 대설・결빙 중 선택.
- 동적 기상 피드: 이문동 한국외국어대학교 서울캠퍼스의 실시간 기상 통계(강수 강도, 풍속, 결빙 여부 등) 표시.
- 안전 체크리스트: 즉각적인 대피 준비 사항(가스 차단, 엘리베이터 이용 금지 등)을 동적으로 안내.
- 대피 버튼: 챗봇 진입을 위한 맥동(pulsing) 원형 버튼.

### 💬 2. 접근성 챗봇 (Steps 1–3)
- Step 1: 대상 그룹: 어린이(👶), 성인(🧑), 고령자(👵), 임산부(🤰), 장애인(👩‍) 중 선택.
- Step 2: 동행 여부: 혼자, 어린이 동반, 고령자 동반, 반려동물 동반 중 선택.
- Step 3: 이동 수단: 도보, 자동차, 휠체어/유모차 중 선택.
- 긴급 상황에서의 신속하고 간편한 사용을 위해 모든 선택은 클릭 방식으로만 진행.

### 📊 3. 대피소 추천 대시보드 (Step 4)
- TOP 3 대피소: 최적 대피소 목록 표시. 적합도 점수, 혼잡도 게이지, 보유 시설(휠체어 경사로, 의료실, 반려동물 구역) 안내.
- 인터랙티브 SVG 지도:
- 외대 정문 출발 위치 및 주변 도로 표시.
- 혼잡도에 따라 색상 코딩 및 동적 크기 조정된 대피소 원형 마커 표시.
- 차단된 경로는 빨간 점선, 안전 우회 경로는 빛나는 초록 애니메이션 선으로 표시.
- 경로 안내 카드: 이동 속도에 따른 상세 도보 안내 및 예상 소요 시간 표시.

## 🗺️ 실시간 위험 구역 우회 (한국외대 서울캠퍼스)

| Disaster Type | Active Hazards | Affected Routes & Detours |
| :--- | :--- | :--- |
| **호우・침수 (Flood)** | - 중랑천 범람 <br>- 이문 지하차도 침수 | - **쌍용아파트 지하대피소**가 차수막 차단으로 비활성화됩니다. <br>- **이문초등학교** 경로는 중랑천을 피해 동편 안길로 우회합니다. |
| **지진 발생 (Earthquake)** | - 천장산 사면 낙석 <br>- 외대앞역 상가 외벽 붕괴 | - **오바마홀**이 철골 내진 설계로 우선 추천됩니다. <br>- 외대앞역 골목 붕괴를 피해 대로변 보도를 이용해 통행합니다. |
| **산불 확산 (Wildfire)**| - 천장산 산불 급속 번짐 | - 서쪽에 접한 **이문1동 주민센터**는 산불 저지선 위험 구역으로 전면 통제됩니다. |
| **대설・결빙 (Heavy Snow)** | - 천장산 사면 도로 빙판 <br>- 이문고개 오르막 정체 | - 경사가 심한 골목 대신 제설이 신속히 이뤄진 오바마홀과 대로를 권장합니다. |

## 🟢 시각적 혼잡도 마커
- 청사진 지도에서 대피소 핀은 실시간 혼잡도에 따라 크기가 조정됩니다:
- 여유 (50% 미만): 소형 초록 원 (반지름 3px). 안전하고 여유로운 상태.
- 보통 (50%–85%): 중형 주황 원 (반지름 4.5px). 중간 수준의 혼잡 상태.
- 혼잡 (85% 초과): 대형 빨간 맥동 원 (반지름 6.5px). 다른 대피소로의 이동을 권장.
